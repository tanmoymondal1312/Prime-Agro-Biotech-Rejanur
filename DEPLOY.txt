  TECHNOLOGY STACK

  DEPLOYMENT TARGET
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Upload path:  /home/{username}/{your-domain-folder}/

  Example:
    If your cPanel username is  rezaportal
    and your domain folder is   khamar.primebiotech.com
    → upload everything to:
      /home/rezaportal/khamar.primebiotech.com/

  How to find your domain folder path:
    cPanel → Addon Domains (or Domains)
    → Look at "Document Root" column next to your domain
    → That is the exact path to upload to

  Your site will be live at:  https://yourdomain.com/


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 1 — Create MySQL Database on cPanel
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  1. cPanel Login → MySQL Databases

  2. Under "Create New Database":
       Database Name:  khamar_portal
       → Click "Create Database"

  3. Under "Create New User":
       Username:   khamar
       Password:   (set a strong password)
       → Click "Create User"

  4. Under "Add User to Database":
       User:       khamar
       Database:   khamar_portal
       → Click "Add" → tick "ALL PRIVILEGES" → Make Changes

  5. Note your values:
       DB_HOST = localhost
       DB_NAME = cpanelusername_khamar_portal  ← cPanel prefixes it
       DB_USER = cpanelusername_khamar          ← cPanel prefixes it
       DB_PASS = (password you set above)

  NOTE: Tables are auto-created on first login — no SQL import needed.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 2 — Configure api/.env
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Open the file:  api/.env  on your local computer and edit:

  APP_PHONE=01712345678
  APP_PASSWORD=YourStrongPassword

  DB_HOST=localhost
  DB_PORT=3306
  DB_NAME=cpanelusername_khamar_portal
  DB_USER=cpanelusername_khamar
  DB_PASS=YourDatabasePassword

  Save the file. This file will be uploaded in Step 4.

  IMPORTANT: api/.htaccess blocks all web access to api/.env


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  STEP 3 — Build Frontend on Your Computer
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Requirement: Node.js 18+ installed on your computer.

  Open terminal in project folder:

    npm install
    npm run build

  A  dist/  folder is created. This is what gets uploaded.

  If build fails with "Cannot find native binding" error:
    Linux:    npm install @tailwindcss/oxide-linux-x64-gnu
    Mac M1+:  npm install @tailwindcss/oxide-darwin-arm64
    Mac x64:  npm install @tailwindcss/oxide-darwin-x64
    Windows:  npm install @tailwindcss/oxide-win32-x64-msvc
  Then run npm run build again.

  STEP 4 — Upload to Your Domain Folder
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  cPanel → File Manager
  Navigate to:  /home/{username}/{your-domain-folder}/

  Example path: /home/rezaportal/khamar.primebiotech.com/

  Click Settings (top-right) → enable "Show Hidden Files"

  ── A. Upload contents of dist/ ─────────────────────────────────
  Open the dist/ folder on your computer.
  Select ALL files inside dist/ and upload to /public_html/

  Files to upload from dist/:
    index.html
    .htaccess                ← CRITICAL — enables page refresh
    assets/                  ← JS + CSS bundle folder
    logo.png
    portal-logo.png
    icons/
    NotoSansBengali-Regular.ttf
    NotoSansBengali-Bold.ttf
    manifest.json
    sw.js

  ── B. Upload api/ folder ───────────────────────────────────────
  Upload the entire  api/  folder into /public_html/

  Files inside api/ to upload:
    .htaccess
    .env                     ← configured in Step 2
    auth.php
    db.php
    profiles.php
    profile.php
    cows.php
    cow.php
    krishi_profiles.php
    krishi_weather.php
    krishi_plans.php
    takatrack_borrowers.php
    takatrack_loans.php
    takatrack_my_debts.php
    takatrack_stocks.php

  ── C. Create uploads/ folder ───────────────────────────────────
  In File Manager, inside /public_html/ create:
    New Folder: uploads
    New Folder: uploads/profiles
    New Folder: uploads/animals

  Right-click each folder → Permissions → set to 755

  STEP 5 — cPanel Server Settings
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  PHP Version:
    cPanel → MultiPHP Manager → select domain → PHP 8.1 or 8.2

  PHP Extensions (enable all):
    cPanel → PHP Selector → Extensions → enable:
      pdo  |  pdo_mysql  |  json  |  mbstring  |  gd

  Folder Permissions:
    /home/{username}/{domain-folder}/uploads/          → 755
    /home/{username}/{domain-folder}/uploads/profiles/ → 755
    /home/{username}/{domain-folder}/uploads/animals/  → 755
    /home/{username}/{domain-folder}/api/              → 755

  STEP 6 — Verify Deployment
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Test 1 — Login page loads:
    https://yourdomain.com/
    → Should show রেজা পোর্টাল login screen

  Test 2 — PHP + MySQL works:
    https://yourdomain.com/api/profiles.php
    → Should return:  []
    → If error shows instead, check api/.env DB credentials

  Test 3 — Login works:
    Enter phone + password from api/.env → should enter portal

  Test 4 — Page refresh works:
    Go to https://yourdomain.com/khamar → press F5
    → Should NOT show 404
    → If 404, re-upload .htaccess from dist/

  Test 5 — Photo upload works:
    Add a profile/animal with a photo
    → Photo should appear after saving
    → If not, check uploads/ folder permissions (755)

  TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Blank/white screen
  → index.html is missing from public_html/
  → .htaccess is missing (enable Show Hidden Files and re-upload)

  404 on page refresh
  → .htaccess is missing from public_html/ root
  → Re-upload .htaccess from the dist/ folder

  Login error "credentials not configured"
  → api/.env is missing or placed in wrong folder
  → Must be at:  public_html/api/.env

  503 error / data not saving (Khamar)
  → Wrong DB_NAME or DB_USER in api/.env
  → Remember: cPanel prefixes DB name/user with cPanel username
  → e.g.  mysite_khamar_portal  not just  khamar_portal
  → Check cPanel → Error Logs for exact message

  Photos not uploading
  → uploads/profiles/ and uploads/animals/ folders missing
  → Or folder permissions not set to 755
  → PHP gd extension must be enabled

  PDF not opening
  → Allow popups in browser (PDF opens in new tab)
  → NotoSansBengali .ttf files must be in public_html/

  RE-DEPLOYING AFTER CODE CHANGES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

  Every time you update the code:

  1.  npm run build               ← generates new dist/
  2.  Upload dist/assets/         ← only assets/ changes each build
  3.  Upload dist/index.html      ← always re-upload this too

  PHP files changed?
  → Upload only the changed .php files in api/

  api/.env changed?
  → Upload api/.env again
