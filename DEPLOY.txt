  TECHNOLOGY STACK (ব্যবহৃত প্রযুক্তি)
════════════════════════════════════════════════════════════════

  FRONTEND (ক্লায়েন্ট সাইড)
  ──────────────────────────
  • React 19          — UI framework (component-based)
  • TypeScript        — Type-safe JavaScript
  • Vite 6            — Build tool & dev server
  • Tailwind CSS v4   — Utility-first styling
  • React Router v7   — Client-side routing (SPA)
  • Framer Motion     — Animations & transitions
  • Recharts          — Charts & data visualization
  • Lucide React      — Icon library
  • html2canvas       — HTML-to-image (PDF generation)
  • jsPDF             — PDF creation (sale receipts)
  • date-fns          — Date formatting

  BACKEND (সার্ভার সাইড)
  ───────────────────────
  • PHP 8.x           — API endpoints (REST)
  • MySQL 8.x         — Database (profiles, cows, transactions)
  • PDO               — PHP database abstraction layer

  APPS INSIDE THE PORTAL
  ───────────────────────
  • /home             — Portal home (app selector)
  • /khamar           — রেজার খামার (Cow/Goat farm management)
                        └── MySQL backend via PHP API
  • /krishi           — সমন্বিত কৃষি ট্রেড (Agricultural trade)
                        └── Browser localStorage
  • /hisab            — দেনা পাওনার হিসাব (Loan tracker)
                        └── Browser localStorage

  AUTHENTICATION
  ──────────────
  • Token-based login via api/auth.php
  • Credentials stored in api/.env (server-side, never exposed)
  • Login token persists in browser localStorage


════════════════════════════════════════════════════════════════
  PRE-DEPLOYMENT CHECKLIST
════════════════════════════════════════════════════════════════

  Before uploading, confirm you have:
  [ ] Node.js 18+ installed on your local machine
  [ ] A cPanel hosting account with PHP 8.0+ and MySQL
  [ ] Your domain or subdomain ready
  [ ] FTP/File Manager access to public_html
  [ ] MySQL database created on cPanel
  [ ] api/.env file configured (see Step 1)


════════════════════════════════════════════════════════════════
  STEP 1 — Configure api/.env
════════════════════════════════════════════════════════════════

  Edit the file at:  api/.env

  ┌─────────────────────────────────────────────────────────┐
  │  APP_PHONE=01712345678       ← login mobile number      │
  │  APP_PASSWORD=YourPassword   ← login password           │
  │                                                         │
  │  DB_HOST=localhost                                      │
  │  DB_PORT=3306                                           │
  │  DB_NAME=your_db_name        ← MySQL database name      │
  │  DB_USER=your_db_user        ← MySQL username           │
  │  DB_PASS=your_db_password    ← MySQL password           │
  └─────────────────────────────────────────────────────────┘

  ⚠  IMPORTANT:
     • Never upload .env.example to the server
     • The api/.htaccess blocks direct web access to api/.env
     • Use strong credentials — this protects all farm data


════════════════════════════════════════════════════════════════
  STEP 2 — Create MySQL Database on cPanel
════════════════════════════════════════════════════════════════

  1. cPanel → MySQL Databases
  2. Create a new database  (e.g. username_khamar)
  3. Create a new database user with a strong password
  4. Add user to database — grant ALL PRIVILEGES
  5. Note the database name, username, and password
  6. Update api/.env with these values (DB_NAME, DB_USER, DB_PASS)

  NOTE: All tables are created automatically on first API call.
        No SQL import needed — db.php handles migrations.


════════════════════════════════════════════════════════════════
  STEP 3 — Build the Frontend on Your Computer
════════════════════════════════════════════════════════════════

  Requirements: Node.js 18+ must be installed locally.

  Open terminal in project folder and run:

    npm install
    npm run build

  This creates a  dist/  folder with the compiled website.

  ⚠  If build fails with "Cannot find native binding":
       Linux:   npm install @tailwindcss/oxide-linux-x64-gnu
       Mac M1+: npm install @tailwindcss/oxide-darwin-arm64
       Mac x64: npm install @tailwindcss/oxide-darwin-x64
       Windows: npm install @tailwindcss/oxide-win32-x64-msvc
     Then run:  npm run build  again.


════════════════════════════════════════════════════════════════
  STEP 4 — Upload Files to cPanel
════════════════════════════════════════════════════════════════

  1. Login to cPanel → File Manager

  2. Navigate to your web root:
       Main domain   → /public_html/
       Subdomain     → /public_html/subdomain/

  3. Click Settings (top-right) → enable "Show Hidden Files"
     (required to see .htaccess files)

  4. Upload CONTENTS of dist/ to web root:
       ✓ index.html
       ✓ .htaccess          ← CRITICAL for page refresh to work
       ✓ assets/ folder
       ✓ logo.png
       ✓ portal-logo.png
       ✓ icons/ folder
       ✓ NotoSansBengali-Regular.ttf
       ✓ NotoSansBengali-Bold.ttf
       ✓ manifest.json

  5. Upload the entire  api/  folder to web root:
       ✓ api/.htaccess
       ✓ api/.env           ← your credentials (configured in Step 1)
       ✓ api/auth.php
       ✓ api/db.php
       ✓ api/profiles.php
       ✓ api/profile.php
       ✓ api/cows.php
       ✓ api/cow.php
       ✓ api/krishi_profiles.php
       ✓ api/krishi_weather.php
       ✓ api/krishi_plans.php
       ✓ api/takatrack_borrowers.php
       ✓ api/takatrack_loans.php
       ✓ api/takatrack_stocks.php
       ✓ api/takatrack_my_debts.php

  6. Create uploads/ folder structure on server:
       /public_html/uploads/
       /public_html/uploads/profiles/     (chmod 755)
       /public_html/uploads/animals/      (chmod 755)

  Final directory structure on server:
  ┌─────────────────────────────────────────────────────────┐
  │  /public_html/                                          │
  │  ├── index.html                ← from dist/             │
  │  ├── .htaccess                 ← SPA routing (MUST!)    │
  │  ├── assets/                                            │
  │  ├── logo.png                                           │
  │  ├── portal-logo.png                                    │
  │  ├── NotoSansBengali-Regular.ttf                        │
  │  ├── NotoSansBengali-Bold.ttf                           │
  │  ├── icons/                                             │
  │  ├── manifest.json                                      │
  │  ├── api/                                               │
  │  │   ├── .htaccess                                      │
  │  │   ├── .env                  ← credentials            │
  │  │   ├── db.php                                         │
  │  │   ├── auth.php                                       │
  │  │   ├── cows.php                                       │
  │  │   └── [all other .php files]                         │
  │  └── uploads/                                           │
  │      ├── profiles/             ← profile photos         │
  │      └── animals/              ← animal photos          │
  └─────────────────────────────────────────────────────────┘


════════════════════════════════════════════════════════════════
  STEP 5 — Server Configuration on cPanel
════════════════════════════════════════════════════════════════

  PHP Version:
    cPanel → MultiPHP Manager → set PHP 8.0 or 8.1 or 8.2

  PHP Extensions (must be enabled):
    cPanel → PHP Selector → Extensions:
    ✓ pdo
    ✓ pdo_mysql
    ✓ json
    ✓ mbstring
    ✓ gd  (for image resizing)

  Folder Permissions:
    uploads/          → 755
    uploads/profiles/ → 755
    uploads/animals/  → 755
    api/              → 755

════════════════════════════════════════════════════════════════
  TROUBLESHOOTING
════════════════════════════════════════════════════════════════

  PROBLEM: White screen / blank page
  FIX:
    • Confirm index.html is at the web root (not inside dist/)
    • Confirm .htaccess from dist/ is uploaded (Show Hidden Files)
    • cPanel → Error Logs → check for JS/PHP errors

  PROBLEM: Page refresh shows 404 Not Found
  FIX:
    • .htaccess is missing from web root — re-upload it
    • Enable "Show Hidden Files" in File Manager to see it

  PROBLEM: Login fails — "Server credentials not configured"
  FIX:
    • api/.env is missing or not inside the api/ folder
    • Check APP_PHONE and APP_PASSWORD are set correctly
    • No spaces around = sign:  APP_PHONE=01712345678  ✓

  PROBLEM: রেজার খামার — data not saving / 503 error
  FIX:
    • api/.env is missing DB_ variables
    • MySQL user does not have permission on the database
    • PHP pdo_mysql extension is not enabled
    • Check cPanel → Error Logs for exact PHP error

  PROBLEM: Photos not uploading
  FIX:
    • uploads/ folder does not exist on server — create it
    • uploads/profiles/ and uploads/animals/ need 755 permissions
    • PHP gd extension must be enabled
    • Check PHP upload_max_filesize in cPanel → PHP Settings

  PROBLEM: PDF download not working
  FIX:
    • PDF is generated client-side (no server needed)
    • Ensure NotoSansBengali-Regular.ttf and -Bold.ttf are uploaded
    • Allow popups in browser (PDF opens in new tab)

  PROBLEM: Texts showing white / invisible colors on mobile
  FIX:
    • Disable "Force Dark Mode" in Chrome:
      chrome://flags → search "dark" → Disable
    • Or update Chrome/Edge to latest version

  PROBLEM: /api/profiles.php returns error (not empty array)
  FIX:
    • Check cPanel → MySQL Databases → user has ALL PRIVILEGES
    • Verify DB_HOST, DB_NAME, DB_USER, DB_PASS in api/.env
    • Check cPanel → Error Logs for the exact PDOException


════════════════════════════════════════════════════════════════
  HOW THE SYSTEM WORKS
════════════════════════════════════════════════════════════════

  AUTHENTICATION FLOW:
    Browser → POST /api/auth.php → PHP reads api/.env
           → credentials match → returns token
           → token stored in localStorage → user logged in
    Token expires only when user logs out or clears browser data.

  রেজার খামার DATA FLOW:
    Browser → GET/POST/PUT/DELETE /api/*.php → PHP → MySQL
    All farm data (profiles, animals, transactions, photos)
    is stored permanently in MySQL on the server.

  সমন্বিত কৃষি ট্রেড DATA FLOW:
    All data stored in browser localStorage only.
    Data is device-specific — does not sync between devices.

  দেনা পাওনার হিসাব DATA FLOW:
    All data stored in browser localStorage only.
    Data is device-specific — does not sync between devices.

  PDF RECEIPTS:
    Generated 100% in the browser using html2canvas + jsPDF.
    No server involvement — works offline after page loads.
