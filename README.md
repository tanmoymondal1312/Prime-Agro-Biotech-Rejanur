# Prime Agro Biotech — রেজা পোর্টাল

Farm & cattle management PWA for **Prime Agro Biotech Limited**, built for client **Rejanur** (01737269938).

## প্রজেক্টের ধরন

This is a **single-page application (SPA)** that manages:

- **রেজার খামার (Khamar)** — Cattle (cow/goat) farm management with full lifecycle tracking: add animals, track loans, treatment costs, sales, profit/loss breakdown, PDF receipt generation
- **কৃষি ট্রেড (Krishi)** — Agricultural trade tracking with expenses, sales, stock management, weather logs, and farm planning
- **দেনা পাওনার হিসাব (Hisab)** — Debt & loan tracking with borrower management, payment history, stock inventory, and personal debt records

## Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 19 + TypeScript + Vite 6 + Tailwind CSS v4 |
| Routing | React Router v7 (SPA) |
| Animation | Framer Motion |
| Charts | Recharts |
| PDF | html2canvas + jsPDF (client-side) |
| Backend | PHP 8.x (REST API) |
| Database | MySQL 8.x (PDO) |
| Hosting | cPanel + Cloudflare |
